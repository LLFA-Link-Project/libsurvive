表示と時刻について

元データの位置を平滑化・間引きせずに読み込みます。画面更新より速い変化は軌跡とグラフで確認してください。20 ms を超える欠測、無効姿勢、センサー時刻の逆行をまたぐ線や補間は描きません。

native の時間軸は記録の受信秒です。tick / Hz は別のセンサー時計で、1 サンプルの変化量はセンサー時計があるときはその時間差で判定します。Monado / Valve JSONL は clock_sync 先頭からの callback 秒です。この二つを自動的に同期させません。

位置は表示区間の最初の有効姿勢からの変位です。B も独立した先頭位置を原点にするため、絶対位置の較正差は比較できません。デバイス軸表示も区間先頭で固定します。回転倍率を変えると実際より大きく回転して表示します。

3D の箱は IMU / 記録参照点を中心とする模式図で、実機形状・grip の再現ではありません。グラフには倍率を適用しません。静止判定時間はフィルター内の判定値です。
